Podstawy Programowania w C++ - Repozytorium Kursu

Repozytorium zawiera kompletny zestaw programów zrealizowanych w ramach kursu "Podstawy programowania C++". 
Projekty prezentują praktyczne wykorzystanie mechanizmów języka C++. Kurs zaczyna się od zupełnych podstaw takich jak 
wyświetlanie danych wyjściowych czy przypisywanie
zmiennych. Zadania porządnie pomagają utrwalić wiedzę z danych zagadnień co ułatwia płynne przejście do następnych tematów.
Przy realizacji projektów pomogła mi również strona w3schools.


Instrukcja uruchamiania programów:

Każdy plik .cpp jest autonomicznym programem. Można go otworzyć pojedynczo i uruchomić.
Do uruchomienia programów wymagany jest dowolny kompilator obsługujący standard C++11 lub nowszy.
Kody zostały napisane w środowisku Dev - C++. 

Możliwa jest również kompilacja z poziomu konsoli. Po otworzeniu terminalu w folderze z wybranym plikiem,
należy wpisać polecenie:
 ```bash
   g++ -std=c++11 nazwa_pliku.cpp -o program
